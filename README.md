# meld-macos-silicon-native

Независимый прототип для Apple Silicon. Интерфейс написан на SwiftUI и AppKit. Границы блоков для попарного сравнения текста вычисляет модуль из Meld 3.24.1.

## Сборка и запуск

Нужны macOS 14 или новее и Xcode Command Line Tools с Swift и Python 3. Из каталога проекта:

```sh
./build.sh
open MeldMac.app
```

Открыть две папки или два файла при запуске:

```sh
open -n MeldMac.app --args "/полный/путь/слева" "/полный/путь/справа"
```

В сравнении папок нажмите имя файла, чтобы открыть пару в отдельной вкладке. Зелёная строка со стрелкой позволяет скопировать файл на пустую сторону прямо на диске. В текстовой вкладке стрелки переносят отдельные блоки в памяти. Нажмите ⌘S для сохранения или ⌘Z для отмены. Текстовый просмотр поддерживает UTF-8, файлы до 4 МБ и единый тип окончания строк в каждом файле.
